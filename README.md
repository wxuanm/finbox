# FinBox

A professional toolkit for financial market monitoring and asset tracking. | 专业级的金融市场监控与投资工具箱。

## 🛠 Available Tools (现有工具)

*   **[Fund Monitor (基金监控面板)](https://wxuanm.github.io/finbox/fundmonitor/)**: A real-time dashboard for mutual fund monitoring. Features include live NAV estimations, visual performance tracking, customizable fund lists, and local storage persistence. (实时监控基金净值、估算涨跌幅并支持本地自选保存的专业看板。)

## 🚀 Access (访问)

The tools are hosted via GitHub Pages and can be accessed directly from your web browser:

👉 **[Launch Fund Monitor](https://wxuanm.github.io/finbox/fundmonitor/)**
